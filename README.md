## 🚀 How to Run Locally

### Option 1: One-Click PowerShell Server (Recommended)
Open PowerShell in this directory and execute:
```powershell
.\serve.ps1
```
This automatically starts a local HTTP server on `http://localhost:8080/` and opens your default browser.

### Option 2: Direct File Open
You can simply double-click `index.html` in Windows Explorer or open it in any browser (Chrome, Edge, Opera GX, Firefox).

- **Netlify**: Drag and drop the `ethio21-technologies` folder into Netlify Drop.
- **Cloudflare Pages**: Connect your Git repo or deploy via Wrangler.
