🛡️ Technical Code Example: Strict Zero-Base64 Cloud Sanitizer

Every registration payload passes through this sanitizer before reaching Firestore, guaranteeing that large image files (which would consume megabytes) are completely stripped:

// Strips any base64 image strings or blob data URLs before writing to Firestore function sanitizeDocumentForCloud(raw) { const clean = { ...raw }; // Delete all large image fields delete clean.idCardUrl; delete clean.kebeleDocUrl; delete clean.degreeDocUrl; delete clean.photoDataUrl; delete clean.imageBlob; // Scan all object keys to ensure no data:image base64 leaks through Object.keys(clean).forEach(k => { if (typeof clean[k] === 'string' && clean[k].startsWith('data:image')) { delete clean[k]; } }); // Average record weight is now reduced to ~0.8 KB - 1.2 KB of clean text! return clean; }

Month-to-Month Contract Management (Continuations vs. Cancellations)

How active ongoing tutoring contracts are handled in Month 2, Month 3, and beyond without losing history or consuming database space:

🟢 Case A: Contract RENEWS (Continues Next Month)

When parent and tutor decide to continue tutoring for another month:

  1. Stays Live in Firestore: Active contracts remain in astegni_matches. Active contract records are tiny (300 bytes of text) and consume negligible space.
  2. Payment Collection: The coordinator contacts the parent 3 days before month-end and records the renewal payment.
  3. Ledger Sync: Founder clicks ☁️ Sync Confirmed Matches to Sheet. Google Sheet logs the new month's commission row into Matches_Ledger.
  4. Lessons Continue: Lessons proceed smoothly with zero interruption.

🔴 Case B: Contract STOPS (Cancellation / Completion)

When tutoring concludes (e.g., student passed national exam or relocated):

  1. Status Change: Admin switches the match status dropdown to 🔒 Closed (የተጠናቀቀ).
  2. Final Sync: The closure is pushed to Google Sheets to finalize the financial ledger.
  3. Cloud Prune: Because the contract is now permanently finished and archived in Google Sheets and Telegram, it can be deleted from Firestore to free space.
  4. Tutor Slot Frees Up: The tutor automatically gets an open slot to accept a new family!

💡 What if an old parent calls back 6 months later?

Their historical records are permanently preserved in your Telegram Parents Group (`-1003632707084`) and in your Google Sheet. Simply search their phone number or tag (e.g. #AST_P_1234) to see all past tutors and feedback, then create a new match in seconds!
